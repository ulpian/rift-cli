# Rift v1.2.0-alpha

Rift now keeps itself up to date, and it starts faster.

## Install

```sh
# macOS / Linux
curl -fsS https://storage.googleapis.com/rift-e59ea04337d9/v1.2.0-alpha/install.sh | sh
```

```powershell
# Windows PowerShell
irm 'https://storage.googleapis.com/rift-e59ea04337d9/v1.2.0-alpha/install.ps1' | iex
```

Then run `rift` inside any git repository.

## What's new

### Updates, handled for you

- **`rift update`** now installs the newest release. You don't need a link.
- **Rift tells you when an update is out.** Once a day, `rift` and `rift init`
  check for a newer release and ask before installing it. Say no and Rift
  won't ask about that release again. Set `RIFT_NO_UPDATE_CHECK=1` to switch
  the check off.
- **Signed releases.** Every release is signed, and Rift checks the signature
  before it installs an update. There's nothing for you to set up.

### Faster

- **Quicker session starts.** Rift no longer loads its tokenizer to size the
  short note it adds when an agent session begins.
- **Less disk contention.** Rift's local database now lets the dashboard read
  while an agent writes, and skips setup work it has already done.
- **A quieter dashboard.** Canopy only reopens a project's data when it has
  actually changed.

## Upgrading

- **From v1.1.0-alpha:** run
  `rift update --from https://storage.googleapis.com/rift-e59ea04337d9/latest/downloads.tsv`.
  After this release, a plain `rift update` is all you need.
- **From v1.0.0-alpha:** run the install command above.

Your settings, projects and captured history are kept.

## Supported platforms

macOS 11+ (Apple silicon and Intel), Linux x86-64 and ARM64 with glibc 2.28
or newer, and Windows 10+ x64. Session capture supports Claude Code, Codex and
Antigravity.

This is an alpha, so expect rough edges. If something goes wrong, run
`rift doctor --report` in the affected project and include its output with
your report. It contains no paths, names or code.
